# Eupsy — Текущее состояние проекта

**Дата обновления:** 24 октября 2026
**Текущий этап:** Переезд на v2 завершен. Проект готов к коммерциализации.

## Что сделано
- **Архитектура:** Весь проект переведен на Vite + ES-модули.
- **Структура:** HTML в корне (`pages/`), скрипты и стили в `src/`.
- **Компонентный подход:** Единые Sidebar, Topbar, UserMenu, Notifications. Каталог психологов (catalog.js/css) работает как единый компонент для авторизованных и гостей.
- **Функционал:** Календарь, мессенджер, сессии, профили, админка, бронирование и отмена сессий полностью работают на Supabase.
- **UI/UX:** Шапки закреплены, фильтры адаптированы, верстка карточек выровнена.
- **Хостинг:** Настроен деплой на Vercel (psy-platform-v2.vercel.app).

## Текущие ограничения (Технический долг)
1. **Хостинг:** Vercel заблокирован в РФ. Домен eupsy.ru не работает без VPN.
2. **Оплата:** Не подключена (требуется интеграция ЮKassa).
3. **Видео:** Публичный Jitsi (лимит 5 минут на сессию).
4. **Юридические документы:** Страницы `terms.html` и `consent.html` требуют заполнения по 152-ФЗ.
5. **Почта:** Нет интеграции с кастомной почтой (только Supabase Auth).
6. **Отчёты:** Раздел работает на демо-данных.

## План коммерциализации (Roadmap)
1. **Хостинг:** Переезд на Yandex Cloud / Timeweb.
2. **Домен:** Привязка eupsy.ru к новому хостингу.
3. **Оплата:** Подключение ЮKassa (прием платежей, чеки).
4. **Видео:** Подключение JaaS (8x8) для полноценных сессий.
5. **Юридическая база:** Заполнение оферты и согласий.
6. **Тестирование:** Сквозной тест всех сценариев на продакшене.
7. **Подача на грант:** "Сертификат на мечту" (после готовности MVP).
