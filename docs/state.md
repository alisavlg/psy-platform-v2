# Eupsy — Текущее состояние проекта

**Дата обновления:** 24 октября 2026
**Текущий этап:** Сайт успешно развернут в России на собственном домене с HTTPS.

## Что сделано
- **Архитектура:** Полный переезд на Vite + ES-модули.
- **Хостинг:** Переезд с Vercel (заблокирован в РФ) на **Yandex Object Storage**. 
- **Домен и SSL:** Домен `eupsy.ru` делегирован на Яндекс, выпущен бесплатный SSL-сертификат Let's Encrypt (HTTPS работает).
- **Компонентный подход:** Единые Sidebar, Topbar, UserMenu, Notifications, Catalog.
- **Функционал:** Календарь, мессенджер, сессии, профили, админка, бронирование и отмена сессий полностью работают на Supabase.
- **UI/UX:** Шапки закреплены, фильтры адаптированы, верстка карточек выровнена.

## Текущие ограничения (Технический долг)
1. **Оплата:** Не подключена (требуется интеграция ЮKassa и регистрация ИП/самозанятости).
2. **Видео:** Публичный Jitsi (лимит 5 минут на сессию). Требуется переход на JaaS 8x8.
3. **Юридические документы:** Страницы `terms.html` и `consent.html` требуют заполнения по 152-ФЗ.
4. **Почта:** Нет кастомного SMTP.
5. **Отчёты:** Раздел работает на демо-данных.

## План коммерциализации (Roadmap)
1. **Юридическая база:** Заполнение оферты и согласий.
2. **Оплата:** Подключение ЮKassa.

4. **Подача на грант:** "Сертификат на мечту".
