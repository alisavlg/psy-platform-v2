# Eupsy — Текущее состояние проекта

**Дата обновления:** 4 ноября 2026
**Текущий этап:** Видеосвязь работает. Сайт развернут на собственном VPS с HTTPS. Почта настроена. Идет рефакторинг профилей, мессенджера и календаря под единую архитектуру.

## Что сделано
- **Архитектура:** Полный переезд на Vite + ES-модули.
- **Хостинг:** Сайт и TURN-сервер размещены на **VPS в Serv-Tech** (IP `185.170.10.206`).
- **Домен и SSL:** Домен `eupsy.ru` направлен на VPS. Выпущен бесплатный SSL-сертификат Let's Encrypt (HTTPS работает).
- **Видеосвязь:** WebRTC + собственный TURN-сервер (Coturn) на VPS. **Работает!** Проверено звонком между психологом и клиентом. (НЕ ТРОГАТЬ БЕЗ НЕОБХОДИМОСТИ).
- **Почта:** Настроен собственный почтовый сервер (Postfix + OpenDKIM) на VPS. Подключен к Supabase. Регистрация теперь проходит с обязательным подтверждением почты.
- **Авторизация:** Исправлена логика входа (`login.js`). Если пользователь подтвердил почту, но профиля в базе нет — он создается автоматически при первом входе.
- **Компонентный подход:** Единые Sidebar, Topbar, UserMenu, Notifications, Catalog.
- **Функционал:** Календарь, мессенджер, сессии, профили, админка, бронирование и отмена сессий, отзывы — всё работает на Supabase (кроме мессенджера, который сейчас в процессе починки).

1. **Единый Профиль:** Сделать один компонент для всех ролей (Клиент, Психолог, Поддержка, Админ) с разными полями.
2. **Мессенджер:** Восстановить рабочую логику, добавить поддержку ролей (Поддержка пишет от псевдонима).
3. **Календарь:** Сделать единый календарь (все события в одном), но с редактированием в зависимости от кабинета.
4. **RLS (Безопасность):** Настроить строгие правила доступа, чтобы никто не видел чужие данные.
